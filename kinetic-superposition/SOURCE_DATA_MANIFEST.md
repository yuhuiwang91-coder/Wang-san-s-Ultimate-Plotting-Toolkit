# Nature Communications data package manifest

The DOI-ready public-deposition package prepared for the associated manuscript combines the kinetic-analysis code and input datasets in this repository with the figure-level Source Data supplied by the authors.

## Kinetic code and inputs already available in this repository

- `time_temperature_superposition.py`
- `time_pressure_superposition.py`
- `data/hill_temperature.xlsx`
- `data/hill_pressure.xlsx`
- `requirements.txt`
